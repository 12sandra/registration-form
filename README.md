# Simple Registration Form

## Description
This project is a simple registration form that includes various input fields for user information, including name, email, password, and account type. Users can also upload a profile picture, provide their age, and add a short bio. The form requires users to accept terms and conditions before submission.

## Features
- User-friendly registration form
- Required input fields for essential details
- Radio buttons for account type selection
- File upload for profile picture
- Dropdown menu for referral source
- Textarea for user bio
- Checkbox for terms and conditions
- Responsive design

## Technologies Used
- HTML
- CSS

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/simple-registration-form.git
   ```
2. Navigate to the project directory:
   ```bash
   cd simple-registration-form
   ```
3. Open `index.html` in your preferred browser.

## Usage
1. Fill in the required details.
2. Select an account type.
3. Upload a profile picture (optional).
4. Provide additional information such as age and bio.
5. Accept the terms and conditions.
6. Submit the form.
